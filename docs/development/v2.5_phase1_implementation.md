#### 风险指标说明

| 指标 | 计算公式 | 解释 |
|------|---------|------|
| VaR (95%) | 历史分位数 | 95%置信水平下的最大损失 |
| CVaR | 超过VaR的平均损失 | 尾部风险度量 |
| 夏普比率 | (Rp - Rf) / σp | 单位风险超额收益 |
| 索提诺比率 | (Rp - Rf) / σd | 单位下行风险超额收益 |
| 最大回撤 | (峰值-谷值)/峰值 | 最大亏损幅度 |
| Beta | Cov(Rp,Rm)/Var(Rm) | 系统性风险 |

```go
    // 4. 计算 RS 和 RSI

}
```

#### MACD 计算

```go
func (ti *TechnicalIndicators) CalculateMACD(prices []decimal.Decimal, fastPeriod, slowPeriod, signalPeriod int) (*MACDData, error) {
    // 1. 计算快速 EMA (12日)
    // 2. 计算慢速 EMA (26日)
    // 3. 计算 DIF = 快速EMA - 慢速EMA
    // 4. 计算 DEA = DIF的9日EMA
    // 5. 计算 MACD = 2 * (DIF - DEA)
}
```

#### 数值稳定性优化

1. **Tikhonov正则化**: 解决矩阵奇异问题
2. **改进随机数生成**: 使用math/rand替代硬编码

```go
func TestCalculateRSI(t *testing.T) {
    ti := NewTechnicalIndicators()

    assert.NoError(t, err)
    assert.NotNil(t, result)
    assert.True(t, result.RSI.GreaterThanOrEqual(decimal.Zero))
```

```go
func TestCalculateRSI_InsufficientData(t *testing.T) {
```

## 🎓 使用示例

### 技术指标

```go
import "etf-insight/services"

ti := services.NewTechnicalIndicators()
prices := []decimal.Decimal{...}

// RSI
rsi, _ := ti.CalculateRSI(prices, 14)
fmt.Printf("RSI: %.2f, 超买: %v, 超卖: %v\n", rsi.RSI, rsi.Overbought, rsi.Oversold)

// MACD
macd, _ := ti.CalculateMACD(prices, 12, 26, 9)
fmt.Printf("DIF: %.2f, DEA: %.2f, MACD: %.2f\n", macd.DIF, macd.DEA, macd.MACD)
```

### 风险模型

```go
rm := services.NewRiskModels()
returns := []decimal.Decimal{...}

// VaR
var, _ := rm.CalculateHistoricalVaR(returns, 0.95)
fmt.Printf("VaR (95%%): %.2f%%, CVaR: %.2f%%\n", var.VaR, var.CVaR)

// 风险指标
metrics, _ := rm.CalculateRiskMetrics(returns, decimal.NewFromFloat(0.02), nil)
fmt.Printf("夏普比率: %.2f, 最大回撤: %.2f%%\n", metrics.SharpeRatio, metrics.MaxDrawdown)
```
