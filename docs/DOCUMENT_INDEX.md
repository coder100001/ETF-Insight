## 🤝 贡献指南

### 文档编写规范

1. **文件命名**：使用大写字母和下划线，如 `DATA_LAYER_EVOLUTION_PLAN.md`
2. **文档头部**：包含版本、更新日期、维护者信息
3. **内容结构**：使用清晰的标题层级和目录
4. **代码示例**：使用语法高亮和代码块
5. **链接引用**：使用相对路径链接其他文档

### 文档更新流程

1. 创建或更新文档
2. 更新本文档索引
3. 提交Pull Request
4. 代码审查通过后合并
